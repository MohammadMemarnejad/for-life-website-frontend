راهنمای ذخیره و مدیریت تصاویر دورهمی‌ها
==========================================

۱. ساختار پوشه‌ها در زمان توسعه (درون پروژه):
--------------------------------------------
تمام تصاویر باید درون پوشه public/gallery قرار گیرند. برای هر دورهمی می‌توانید یک پوشه اختصاصی بسازید:
- public/gallery/mehr-1403/ (عکس‌های دورهمی مهرماه)
- public/gallery/tea-poetry-1403/ (عکس‌های عصرانه شعر و چای)
- public/gallery/words-workshop-1403/ (عکس‌های کارگاه واژه‌ها)
- و...

۲. نحوه فراخوانی در فایل تنظیمات (src/data/mockData.js):
-------------------------------------------------------
در فایل mockData.js در بخش meetupAlbums، کافیست آدرس تصویر را به این شکل بنویسید:
image: "/gallery/mehr-1403/photo1.jpg"

۳. ساختار در زمان استقرار روی هاست (پوشه dist):
----------------------------------------------
وقتی دستور npm run build را اجرا می‌کنید، پوشه dist ایجاد می‌شود.
پوشه public/gallery عینا به dist/gallery کپی می‌شود.

روی هاست (سی‌پنل، دایرکت‌ادمین و...):
اگر محتویات پوشه dist را درون public_html هاست آپلود کرده‌اید، مسیر تصاویر این‌گونه خواهد بود:
public_html/
   ├── index.html
   ├── assets/
   └── gallery/
          ├── mehr-1403/
          │      ├── photo1.jpg
          │      └── photo2.jpg
          └── tea-poetry-1403/
                 └── photo1.jpg

نکته مهم:
شما حتی می‌توانید بعد از آپلود سایت روی هاست، مستقیما عکس‌های جدید را از طریق File Manager هاست در پوشه gallery/ آپلود کنید و نیازی به بیلد مجدد نخواهد بود!
