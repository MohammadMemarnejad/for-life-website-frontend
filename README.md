# دَمی برای زیستن | Dami Baray Zistan

> **«برای لمسِ لحظه‌ای زندگی در آشوبِ روزمرگی»**

وب‌سایت تعاملی و پلتفرم معرفی رویدادها، دورهمی‌ها و کارگاه‌های «دمی برای زیستن». این پلتفرم فضایی آرامش‌بخش برای اشتراک تجربیات زیسته، پیوند با طبیعت، نشست‌های کتاب‌خوانی، شعرخوانی و ثبت‌نام در گردهمایی‌های حضوری است.

---

## ✨ امکانات و قابلیت‌ها (Features)

- **طراحی زیبا و واکنش‌گرا (Responsive UI):** طراحی مینیمال و آرام با پالت رنگی ارگانیک و فونت فارسی وزیرمتن (Vazirmatn).
- **بخش داستان و ارکان اصلی (Story & Pillars):** معرفی فلسفه شکل‌گیری دورهمی‌ها و سه رکن بنیادین (طبیعت، درنگ، واژه‌ها).
- **بخش ثبت‌نام دورهمی‌ها (Meetup Spotlight & Registration):** مشاهده جزئیات گردهمایی‌های پیش‌رو و امکان رزرو صندلی.
- **گالری و آلبوم تصاویر (Interactive Gallery):** اسلایدر تصاویر در صفحه نخست و صفحه اختصاصی مرور آلبوم‌های رویدادهای گذشته همراه با قابلیت نمایش بزرگنمایی (Lightbox/Modal).
- **پخش‌کننده صوتی و اتمسفر (Ambient Sound Player):** امکان پخش نوای ملایم پس‌زمینه برای ایجاد حس آرامش در حین پیمایش سایت.
- **سیستم ورود و احراز هویت اولیه (Auth Modal):** پنجره تعاملی ورود اعضا.

---

## 🛠️ تکنولوژی‌های به‌کاررفته (Tech Stack)

- **React 18** (با ساختار کامپوننت‌های مدرن و هوک‌ها)
- **Vite 5** (محیط توسعه فوق‌سریع و Bundler بهینه)
- **Tailwind CSS 3** (طراحی اختصاصی و بهینه‌سازی استایل‌ها)
- **Lucide React** (مجموعه آیکون‌های برداری مدرن)
- **PostCSS & Autoprefixer**

## 🚀 راهنمای نصب و اجرای محلی (Getting Started)

### پیش‌نیازها
- [Node.js](https://nodejs.org/) (نسخه ۱۸ یا بالاتر پیشنهاد می‌شود)
- `npm` یا `yarn` یا `pnpm`

### مراحل اجرا

۱. **کلون کردن ریپازیتوری:**
```bash
git clone https://github.com/<username>/dami-baray-zistan.git
cd dami-baray-zistan
```

۲. **نصب وابستگی‌ها:**
```bash
npm install
```

۳. **اجرای سرور توسعه:**
```bash
npm run dev
```
سپس آدرس `http://localhost:5173` را در مرورگر خود باز کنید.

۴. **ساخت نسخه نهایی (Production Build):**
```bash
npm run build
```
فایل‌های کامپایل‌شده و بهینه‌سازی‌شده در پوشه `dist` قرار می‌گیرند.

۵. **پیش‌نمایش بیلد نهایی:**
```bash
npm run preview
```

## 📁 ساختار پروژه (Project Structure)

```text
├── public/                 # دارایی‌های عمومی، فونت‌ها، تصاویر و موسیقی
│   ├── gallery/            # پوشه‌های عکس‌های دورهمی‌ها
│   ├── brand-logo.png      # لوگوی برند
│   └── music.mp3           # قطعه موسیقی پس‌زمینه
├── src/
│   ├── components/         # کامپوننت‌های React تفکیک‌شده بر اساس بخش
│   │   ├── common/         # Navbar, Footer, ...
│   │   ├── home/           # Hero, Story, Meetup, GallerySlider
│   │   ├── gallery/        # گالری کامل و نمایش جزئیات
│   │   ├── about/          # صفحه درباره ما
│   │   └── auth/           # مودال ورود و ثبت‌نام
│   ├── context/            # کانتکست‌های وضعیت برنامه (مانند AuthContext)
│   ├── data/               # داده‌های اولیه و ماک (mockData.js)
│   ├── utils/              # هلپرها و کنترلرهای صوتی (ambientPlayer)
│   ├── App.jsx             # کامپوننت ریشه و مدیریت صفحات
│   ├── index.css           # پیکربندی استایل‌ها و Tailwind
│   └── main.jsx            # نقطه ورود React
├── index.html              # تمپلیت اصلی HTML با فونت Vazirmatn
├── tailwind.config.js      # تنظیمات رنگ‌ها و استایل‌های Tailwind
├── vite.config.js          # تنظیمات Vite
└── package.json            # مشخصات و وابستگی‌های پروژه
```
